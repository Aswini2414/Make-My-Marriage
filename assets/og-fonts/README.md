Fonts for `app/(marketing)/opengraph-image.tsx`. `next/og` needs TTF files, so these are Google Fonts subsets holding only the characters the preview image uses. If you change the image's text, download new subsets with the `text=` parameter, for example:

`https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400&text=<your text>`
